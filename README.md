# Smart Expense Manager

A modern, offline-first personal finance and expense management application built with Flutter and FastAPI.

## Tech Stack

### Mobile

- Flutter
- Dart
- Riverpod
- Drift / SQLite
- Dio
- Material 3

### Backend

- Python
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL

### Planned Features

- Manual income and expense tracking
- Multiple accounts
- Categories
- Monthly budgets
- Bank statement CSV import
- Offline-first operation
- Cloud synchronization
- Spending analytics
- Financial reports
- Future smart insights and predictions
